# Alpha 4 requirement traceability matrix

Directive §4.3 makes this matrix a principal-agent responsibility: every Alpha 4 requirement in
the master execution directive must have a row, and every row must point at the evidence that
satisfies it.

This matrix is maintained by hand and describes **only what the repository actually contains**.
A row moves to `DONE` when the evidence exists on `main`; nothing is marked done because it was
planned, attempted, or believed to work. Where a requirement is partly met, the row says which
part is missing rather than rounding up.

Legend: `DONE` evidence merged and validated · `PARTIAL` some acceptance criteria unmet ·
`NOT STARTED` no implementation · `BLOCKED` waiting on something outside the work itself.

**Last verified:** `c5d35b6` (merge of PR #96), 2026-11-11.

Breadth is therefore 23% of the whole index and is **not** claimed as parity — the document argues explicitly against choosing the denominator after seeing the answer, and lists eight ranked next domains. The row stays `PARTIAL` because 60 modules remain absent. §17.2 has JSON, and now RFC 4180 CSV (`csv_parse`/`csv_write`, quoted fields, embedded delimiters and line breaks, opt-in comments) plus date and instant parsing that produce exactly the shapes `today()` and `now()` produce — 19 tests, specified by [ADR-0035](../adr/0035-csv-and-structured-data.md). XML is deliberately absent: a hand-written parser without XXE hardening would be a security regression, so the gap is recorded rather than filled badly. Date/time serialization is delivered for ISO-8601 dates and instants; §17.3 time-zone arithmetic remains separate and still absent. §17.3 now has time-zone conversion (`tz_convert`, explicit IANA zone, numeric offset out, abbreviations refused), `copy_file`/`move_file` refusing to overwrite, binary content as hex (`read_bytes`/`write_bytes`), recursive `walk` that does not follow symbolic links, and `is_file`/`is_dir` — specified by [ADR-0036](../adr/0036-time-zones-and-filesystem.md), 16 tests. The specification also now records, because it was measured, that `today()` and `datetime()` are local while `now()` and `timestamp()` are UTC. Deterministic close semantics remain unaddressed as a construct: there is no `with` and no `close`, because no builtin returns an open handle, and ADR-0036 records that as a decision rather than an omission. §17.4 now has `run_command`, four `log_*` levels with a threshold from `OQ_LOG_LEVEL`, `log_level`/`log_enabled`, and a declarative `arg_parse` returning `{flags, values, rest}` — specified by [ADR-0034](../adr/0034-logging-and-argument-parsing.md), 18 tests, every behaviour probed against the built CLI before it was written down. §17.5 now has URL parsing and encoding (`url_parse`, `url_encode`/`url_decode`, ordered `query_parse`/`query_encode`, segment-escaping `url_join`) plus two defects repaired in the existing HTTP client: a transport failure no longer reports `HTTP request failed: null` (the cause is classified by type, so a refused connection is distinguished from an unresolved name), and the three HTTP deadlines are named constants instead of literals, with the body deadline no longer borrowing the subprocess timeout — 29 tests, specified by [ADR-0037](../adr/0037-networking-and-urls.md). Sockets and an HTTP server are deliberately absent: neither can be given a deterministic lifetime while the language has no `close`, and ADR-0037 records that as a decision. TLS keeps full JVM certificate and hostname validation with no opt-out. §17.6 hashes, HMAC and a password KDF: `secure_equal` is constant-time via `MessageDigest.isEqual` (opt-in, so `==` is unchanged), and `pbkdf2_sha256(password, salt, iterations)` derives 32 bytes with both inputs required and the count bounded — its output is cross-checked against `hashlib.pbkdf2_hmac` rather than against itself — 18 tests, specified by [ADR-0038](../adr/0038-constant-time-and-password-hashing.md). Key and certificate APIs are refused: a key needs a lifetime and there is no `close`, while certificate validation itself stays on for every `https` request with no opt-out. §17.7 has a mutex and a bounded `await`: `mutex()` closes a measured lost update (two tasks incrementing a shared counter 2000 times each produced 3840/3850/3704, now 4000 on every run), `await(task, seconds)` bounds the wait and raises without cancelling because the interpreter checks for interruption nowhere, and `spawn` now shares one executor instead of abandoning one per call — 11 tests, specified by [ADR-0039](../adr/0039-executors-and-cancellation.md). Executors, cancellation and channels are deliberately absent with the reasons recorded. §17.8 has SQLite through three functions with no connection value: `db_query` reads, `db_execute` writes, and `db_transaction(path, body)` commits on return and rolls back on raise, so a connection is opened and closed inside every call and cannot be leaked — the first API in the language to solve resource lifetime without a `close`. Parameters are always bound, never spliced, and the placeholder count is checked because SQLite treats an unbound placeholder as NULL (measured: a forgotten parameter wrote `nothing` and exited 0). SQL NULL maps to `nothing` in both directions and booleans round-trip as 1/0. 16 tests, specified by [ADR-0040](../adr/0040-database-support.md), which records the cost: the first external runtime dependency, growing the standalone jar from 435 KB to 13.5 MB, and the first JNI dependency, so Alpine/musl is unsupported. A *built* program also carries the driver now, which costs the same 13.5 MB per jar and was not true before: `JarBuilder` copied only `dev.oqthara` classes, so a built database program exited 0 under the interpreter and died at its first query from a jar, then died on `ClassNotFoundException: org.slf4j.LoggerFactory` once the driver alone was added — both prefixes travel and `BuildJarTest` compares the jar's output with the interpreter's. §17.9 asks for an example per module and §17.5–§17.8 had none, so `urls.oq`, `hashing.oq`, `concurrency.oq` and `database.oq` were added and `ExamplesRunTest` runs every example through the real CLI — the examples README had claimed CI did that and nothing did. General JDBC, connection handles and `begin`/`commit`/`rollback` are declined with reasons. `oq doc` was also repaired: it read only `Stdlib.java`, so any built-in defined in its own module file was missing from a page that claims to list every function (126 → 129, and 131 once the two below are counted). §17.3 gained filesystem pattern matching: `glob(directory, pattern)` and `fnmatch(name, pattern)`, sharing one translator from the Python glob dialect to a Java regex. Java's `PathMatcher` was deliberately not used, because its globstar requires at least one directory, so `**/*.oq` would not match a top-level `a.oq` and a program ported from the reference would silently skip files — the wrong-answer failure mode rather than an error. Recursion follows the pattern (only a `**` or a separator walks the tree), results are relative with `/` separators on every host, symbolic links are not followed, and a pattern matching more than a list may hold is an error rather than a truncation; `GlobTest` pins each rule, and every behaviour in the specification passage was probed against the built CLI, including the 100,000-entry cap. §17.2 and §17.3 gained descriptive statistics, identifiers and ordered search: `mean`, `median`, `variance`, `stdev`, `mode`, `percentile`; `uuid` and `is_uuid`; `heap_push`/`heap_pop` and `bisect_left`/`bisect_right` — 12 names, all needing no new type, no dependency and no lifetime rule, specified by [ADR-0041](../adr/0041-statistics-identifiers-and-ordered-search.md) and pinned by 35 tests. Three points are decided rather than left to chance: `variance`/`stdev` are the sample forms dividing by `n - 1` and refuse a single item rather than returning `0`; `mode` returns the smallest on a tie so the call is total where Python raises, and `percentile` interpolates between closest ranks rather than snapping to one; `is_uuid` refuses the braced, `urn:uuid:` and unhyphenated spellings that Java's `UUID.fromString` accepts, because a validator that takes strings other systems reject is worse than none. The `Compression and archiving` chapter gained whole-value compression: `zlib_compress`/`zlib_decompress` for raw DEFLATE, `gzip_compress`/`gzip_decompress` for the gzip container, and `zip_compress`/`zip_decompress` over a map of entry names to hex content — 6 names, 26 tests, specified by [ADR-0042](../adr/0042-whole-value-compression.md), which moves the `Compression and archiving` chapter from 0/8 to 3/8 and removes rank 2 from the absent list. The cap is the point of the ADR: decompression counts the bytes it actually produces and stops at 16 MiB with a named error, because enforcing a cap by reading a length field from the input places the attack exactly where the defence should be — a hostile producer writes whatever length it likes. The obvious implementation, `readAllBytes()` on an `InflaterInputStream`, allocates the entire expansion before any cap can apply and therefore does not implement the cap at all; inflating in chunks and testing the running total after each is what makes the guarantee real. Zip entry names that are absolute, contain a `..` segment, a backslash or a NUL are refused rather than normalised, since a name that had to be rewritten is not the name the caller asked for |

## Ordering

`§10` overload dispatch (PR #44) landed before `§14`, so the matrix records it as delivered
out of the directive's sequence. This is a note about order, not a defect: overload selection
was a prerequisite for method dispatch in classes, and building it first avoided a rewrite.

## How a row is closed

A row may move to `DONE` only when all of the following hold on `main`:

1. The implementation is merged through a protected pull request with all required checks green.
2. The behaviour is pinned by a test that has been shown to fail without the change.
3. The specification and any ADR describe the behaviour as implemented, not as intended.
4. The conformance baseline has been re-measured rather than adjusted by hand.

Anything less is `PARTIAL`, and the row says what is missing.
