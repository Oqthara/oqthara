## What was examined

The second reviewer read the whole diff of `518cac7` against `0635cc2`, ran
`python3 -m unittest discover -s scripts/tests -p 'test_*.py'`, and reproduced the deferral
bypass and the URL-as-model bypass by hand against a scratch repository before reporting them.
It verified each of the first round's thirteen findings against the code rather than against the
commit message.

Not covered: the gate's behaviour on a pull request opened by an account this repository has
never seen; the behaviour of `gh` under a token with the wrong scope other than `contents`;
and whether the machine checks measure review *quality*, which they do not and cannot. The
policy states that limitation. No human review was performed, requested, or claimed.
