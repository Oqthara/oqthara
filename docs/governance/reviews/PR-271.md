## What this round was worth

§3 asked for a scope record. Writing one exposed four errors, and none of them were in the scope —
they were in the citations supporting it.

That is the report's own pattern, found for the fifth time: prose about the tree is not checked
against the tree. The refusals list was cited to a file with no matching rows. The exclusions table
pointed at an item about a different subject. Two documents were credited with a back-reference that
does not exist. `AGENTS.md` was credited with a section that lives somewhere else. Every one of these
reads as researched. None was checked.

The gate is the fix that matters, because the other four were corrected by hand and hand corrections
do not survive. Before this change:

```
$ sed -i '' 's/The twelve are/The thirteen are/' docs/governance/alpha-7-first-report.md
$ python3 scripts/check-report-claims.py
report claims: every figure agrees — 28 probes, 29 probe files, 55 capability rows,
13 directions, 22 keywords, 14 fuzz targets, 70 ADRs, 6 defects, 31 risks (5 Open)
[exit 0]
```

After:

```
$ sed -i '' 's/The twelve ADR-0062 refusals/The eleven ADR-0062 refusals/' docs/governance/alpha-7-first-report.md
$ python3 scripts/check-report-claims.py
report claims: 1 problem(s)
  - line 319: says eleven refusals but the tree has 12
[exit 1]
```

The scope record is worth having on its own terms — Item 6 had reported "Unblocked" for three passes
while the section it cleared was described nowhere — but the durable part is that the figure it
quotes can no longer drift silently.

## What this review does not claim

It does not claim the scope record is complete. It transcribes the order's §3; where the order and
this repository disagree, the discrepancy is a finding to record, and none was found in this pass.

It does not claim the refusals list will stay at twelve. If a future change implements one, the
matrix row's status changes and `check-report-claims.py` fails until the prose matches — which is
the intended behaviour, not a regression.

It does not claim independent review. The same session wrote the change and audited it, which
ADR-0059 requires be stated rather than glossed.
