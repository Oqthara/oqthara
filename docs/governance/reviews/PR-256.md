## What this round was worth

The change is documentation and a file rename; no behaviour moved. It still earns a pull request
because the two high findings are the same defect in different clothes: **a governance document
asserted something about the tree that the tree contradicted, and nothing checked.** The report was
written from a reading of the Alpha 5 inventory that was itself correct at the time of the audit but
superseded by PR #231 before the report shipped. Neither the report nor the inventory's A6.4 row was
wrong when first written in isolation; they were wrong together, and no gate compares a governance
claim against the commits that followed it.

That is R-031's shape again — the register already records that no gate is exercised against live
data, and this is the documentation equivalent. What caught it here was mechanical: running the
five `d1_*` probes instead of reading the sentence that said they would fail. The lesson worth
carrying is narrow and repeatable — a governance document that names a defect should be checked by
executing the defect's reproduction, not by re-reading its prose.

Finding 2 is a smaller instance of the same thing. The number five propagated from a single
misnamed file into two documents and survived three review rounds, because counting sections is
something a reader does from memory and something `grep` does exactly.

## Not verified

- `./gradlew build` was not re-run for this change. Both commits touch only Markdown and one `.oq`
  probe filename plus the Python harness that names it; the Java sources are untouched, so the
  conformance and unit suites cannot observe the change. The probe harness above is the executable
  check that covers it. This is a judgement, not a measurement, and is recorded so a later reader
  can disagree with it rather than assume the full build ran.
- The renamed probe has not been exercised by a *fresh* CI run at the time this record was written;
  the local harness run above is the evidence available at review time.
- No gate checks whether a governance document's claim about the tree still holds. Finding 1 is
  therefore fixed by hand and will recur the same way. R-031 already records the analogous gap for
  the automated gates; this record adds that governance prose has the same exposure and no owner.
