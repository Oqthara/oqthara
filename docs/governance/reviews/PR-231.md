### What the reviewer confirmed as correct

These were checked rather than assumed, and are recorded so a later reader knows the fix was
examined and not merely asserted:

- D1 is genuinely fixed across all four builtins; each probe calls the Java value directly first, so
  a failure separates "not callable" from "the builtin would not take it".
- The `VARIADIC == -1` sentinel is handled correctly at both new sites, and there is no third site.
- Statics are still tried before the class-object fallback, so there is no regression for programs
  that worked before.
- Widening `OqMutex.lock`'s body parameter from `OqCallable` to `Object` is safe.
- The allowlist has exactly 22 entries and every one is present in the inventory.
