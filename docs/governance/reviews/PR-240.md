## Findings

Four findings were consolidated from one round: no critical, no high, two medium, two low. All four
are applied.

The most useful finding was about what the evidence actually proved. The ADR's decisive premise is
that reflection is reachable through `MethodHandles`, and the first probe demonstrated it with
`String.trim`. But `trim` is a member the language already reaches by name on an ordinary string,
so the probe showed only that `findVirtual` works, not that it reaches anything the allowlist
refuses. Re-examining `JavaBridge` showed `getSuperclass` is on the allowed list too, so a second
candidate proof was also weak. The claim was then re-tested on `ArrayList` — a class whose
`getDeclaredMethod` is refused by name — where `findVirtual(…, "length", …)` resolves and
`c.getSimpleName()` still works, and where the program builds with `codepath: compiled bytecode`.
That is the proof the ADR needs, and the probe now rests on a class object that is actually refused
something.
