## What this round was worth

Item 8 is the weakest-specified entry in the Alpha 7 report: one line, no criteria, and an owner
citation that points at the typing section. The temptation is to invent a large observability
feature and call the item closed. Measuring first was the whole value of this round.

The measurement found that most of what "observability" suggests already exists. Elapsed time is
available through `timestamp()`; an earlier draft of the new report section asserted the opposite,
having tried `now()` — which returns text — and stopped there. That draft was wrong and was caught
before it was committed. `memory_mb()`, `type_of()`, spanned diagnostics and exit-status mapping all
work.

What did not exist was cheaper and more embarrassing: two of three file-taking subcommands could
not answer `--help`. The fix is a guard copied from the sibling that already had one, plus a
missing-file check. It is a small pull request because the evidence said the gap was small, not
because the work was cut short.

## Not verified

- **No execution tracing was added**, so nothing here tests one. Whether a trace belongs on stderr,
  in a file, or as an Oqthara value is unrecorded, and this pull request deliberately does not decide
  it.
- **`oq run`'s new `-` rejection has no test for an argument that is a legitimate path starting with
  a hyphen.** Such a path was already unusable before this change, so nothing regressed, but the
  behaviour is now explicit and still untested.
- **The other subcommands were not audited.** `oq fmt`, `oq repl`, `oq doc` and `oq test` were not
  checked for the same `--help` mistake, so the fix covers the two commands that were observed
  failing rather than every command that might fail the same way.
