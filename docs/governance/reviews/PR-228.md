## Findings

The review was told to break the change rather than approve it. It re-measured every figure in
an isolated worktree at each cited commit, fetched the discarded `5015580` by raw SHA to test the
reproduction claim, mutation-tested the guards, and checked the prose against the repository
rather than against itself. It found six defects, all in my work and none in the change's
premise. All six are fixed.

Two are worth naming. The fix I had already shipped did not work for the branch carrying it: a
depth-1 clone of `main` reported three failures and I generalised from that, but a depth-1
single-branch clone of the *branch* still failed, because it has no `origin/main` for the
ancestry test to resolve. And the guard I used was wrong in a second, quieter way: it keyed on a
repository-wide flag, so a depth-20 clone that contained the pin still skipped the case that
reads it. Both were caught by measurement, not by reading.
