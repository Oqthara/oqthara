## What the review establishes beyond the findings

Finding 1 is the one worth recording separately. The branch exists because a document asserted
something about another file that the other file contradicted — the fifth such entry in this report
across separate PRs. Its repair introduced a sixth instance of the same class while describing the
class, in a sentence about a *section* rather than a file. The class was not "documents go stale".
It is that **a document makes a claim about something it does not check, and no gate re-checks the
claim either**. Nothing in `check-report-claims.py` can tell whether `9j` encloses a citation, just
as nothing can tell whether a file exists.

All 17 findings were reproduced against the tree before being accepted; none was taken on the
reviewer's word. Findings 8 and 9 change what the report *recommends*, not just what it asserts:
the previous text would have sent the next reader to install the wrong package and to escalate
unnecessarily.
