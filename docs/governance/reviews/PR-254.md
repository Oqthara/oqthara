## What this round was worth

The change is two strings in a set, and the interesting part is not the change. Finding 2 is the one
worth keeping: the defect survived review because the test that should have caught it was written
against the same wrong assumption as the code. That is a general shape — a stub test agrees with the
code because both were written from the same belief — and it is the reason the risk's residual says
what it says rather than "fixed".

Finding 3 is the reason the fix is two slugs instead of a wildcard. It was not the first thing I
wrote; the wildcard was, and it would have widened the exemption to every App on the repository to
fix one bot. The test that refuses `app/some-other-automation` exists so that the next person to
reach for `app/*` has to delete a test to do it.
