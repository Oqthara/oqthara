A small language
that reads like pseudocode.

Oqthara runs on the JVM and gives you every Java library, without the classes, the main, the new, the semicolons, or the ceremony. 

name = "World"
print "Hello, {name}!"
curl -fsSL https://raw.githubusercontent.com/JoaoValentimTheo/oqthara/main/scripts/install.sh | bash

No boilerplate

Code at file level. No class, no package, no public static void main.

Data in one line

data Point(x, y) gives you a constructor, fields, equality, hash and text.

Collections that work

.map, .filter, .sort, .sum on every list. No streams.

Errors you can read

Every diagnostic shows the line, a caret, a plain explanation and a fix.

Java when you need it

use java.time.LocalDate and call it with the same dot syntax.

Small surface

18 keywords. One way to do each thing. Nothing to memorize twice.

What it looks like

data Point(x, y)

fun distance(a, b)
  dx = a.x - b.x
  dy = a.y - b.y
  return sqrt(dx * dx + dy * dy)
end

points = [Point(3, 4), Point(6, 8)]
for p in points
  print "distance: {distance(Point(0, 0), p)}"
end
# word count
counts = {}
for word in read("book.txt").lower().words()
  counts[word] = counts.get(word, 0) + 1
end

for word in counts.keys().sort()
  print "{word}: {counts[word]}"
end
use java.time.LocalDate

start = LocalDate(2026, 1, 1)
print "days: {LocalDate.now().toEpochDay() - start.toEpochDay()}"
